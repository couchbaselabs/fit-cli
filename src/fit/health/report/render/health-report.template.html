        Every test that failed recently, night by night

        Each column is one night, oldest on the left. Each test is classed by the shape of its last 30 days, not just how often it failed: one unbroken run of failures means it broke; several separate runs means it's flaky. Tests with no failure in that window are folded away under each suite.

        What this report can't tell you

        • History is perishable. GitHub deletes Actions logs after 90 days and S3 run archives expire after 180, so nights older than that survive only in the fit health store.
        • Log formats change. A night whose CI log is in a format the parser doesn't recognise has no results; those runs are listed at the foot of the page.
        • One SDK only. This report sees only this SDK's nightlies, so it can't tell a flaky test from a flaky SDK.
