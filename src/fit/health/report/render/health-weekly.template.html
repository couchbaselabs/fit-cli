How this is counted

Counted in tests (Class.method), not test cases, over the functional runs only. Failing at week end counts tests in a current failure run, including those only 1-2 nights in; a test that flips between passing and failing is not in it. Every list is a way into or out of that set since last week's end, so last week's count, plus started and new tests failing, minus stopped and no longer counted, is this week's. A test that stops failing late in a week can be listed the week after: the SDK pages call it recovered only after three clean nights. A test name opens its SDK's page at that night; the SDK page shows the state as of today, not as of this week.
